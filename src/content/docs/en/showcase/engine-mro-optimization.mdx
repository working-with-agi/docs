## What the model decides

A mixed-integer linear program (MILP) that decides, for a whole fleet, month by month over several years, **when to remove each engine, which workscope to perform, and how to cover the gap with spares or leases**.

| Element | Content |
|---|---|
| Decisions | Induction month and workscope, engine utilisation, lease count |
| Tracked state | EGT margin, LLP remaining life per module |
| Constraints | Installed positions covered (own spares + leases + AOG), shop slots, EGT / LLP limits |
| Objective | Discounted (shop visits + leases + engine changes + AOG + fuel burn from deterioration) − end-of-horizon asset value |

```
min  Σ_t δ_t · [ shop visits + leases + engine changes + AOG + fuel deterioration ]  −  κ · end value (EGT margin, LLP life)
```

## Why it was built

Three trade-offs — deferring pushes shop cost out but raises fuel burn and AOG risk; advancing throws away LLP life; deeper workscopes cost more but push the next removal further out — cannot be reconciled one engine at a time. Handling all engines, periods and workscopes together shows that a plan respecting fleet-wide shop capacity and spares is achievable.

The model is deterministic (quotes and averages taken at face value). In practice quote overruns, TAT delays and unscheduled removals cannot be ignored, so the business workflow is centred on the part 2 stochastic model (shop quotes as price + risk distribution). This model's output feeds it as removal windows, allowed workscopes and workscope values.

<Aside type="caution" title="About the data">
  The sample fleet data (engine condition, costs, TAT, LLP limits, etc.) is synthetic and does not represent any specific OEM, engine type or airline.
</Aside>
