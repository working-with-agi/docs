## 何を決めるモデルか

フリート全体について、各エンジンを **いつ取り卸し、どのワークスコープで整備し、その間の穴を予備エンジン／リースでどう埋めるか** を、月次・複数年で同時に決める混合整数線形計画（MILP）です。

| 要素 | 内容 |
|---|---|
| 決めること | 入場月とワークスコープ、エンジンの稼働、リース台数 |
| 追跡する状態 | EGT マージン、モジュール別の LLP 残寿命 |
| 制約 | 装着位置の充足（自社予備＋リース＋AOG）、工場の同時入場枠、EGT・LLP の限界 |
| 目的 | 割引後の（整備費＋リース費＋載せ替え費＋AOG＋劣化による燃料増分）− 期末の資産価値 |

```
min  Σ_t δ_t · [ 整備費 + リース費 + 載せ替え費 + AOG + 燃料劣化 ]  −  κ · 期末資産価値（EGT マージン・LLP 残寿命）
```

## なぜ作ったか

「先送りすれば整備費は後ろに回るが燃料費と AOG リスクが増える」「前倒しすれば LLP の残寿命を捨てる」「深いワークスコープは高いが次回の取卸しを遠ざける」という 3 つのトレードオフは、エンジン 1 基ずつの判断では整合がとれません。全エンジン・全期間・全ワークスコープを同時に扱うことで、フリート全体の能力と予備の制約を満たす計画を出せることを確かめるのが目的でした。

このモデルは確定的（見積もりどおり・平均値どおり）に解きます。実務では見積もりの超過や TAT の遅延、非計画取卸しを無視できないため、業務向けの構成では第2弾の確率計画（工場見積もりを価格＋リスク分布として扱う）を中心に据え、本モデルの出力は取卸し可能期間・許容ワークスコープ・ワークスコープの価値として受け渡す位置づけです。

<Aside type="caution" title="データについて">
  サンプルのフリートデータ（エンジン状態、費用、TAT、LLP 寿命など）はすべて合成値であり、特定の OEM・エンジン型式・航空会社の実データではありません。
</Aside>
